# Preflight локальной VM пользователя

Источник: вывод терминала, предоставленный пользователем в этом чате. Команды: `cat /etc/os-release`, `uname -m`, `nproc`, `free -h`, `df -h`. Агент не подключался к VM и не менял её.

| Параметр | Фактическое значение |
| --- | --- |
| ОС | Ubuntu 22.04.5 LTS, Jammy, VERSION_ID=22.04 |
| Архитектура | aarch64 |
| vCPU | 4 |
| Память | total 3.8 GiB, used 681 MiB, available 2.9 GiB |
| Swap | total 3.8 GiB, used 0 B |
| Корневой раздел | `/dev/mapper/ubuntu--vg-ubuntu--lv`, 30 ГБ, занято 15 ГБ, свободно 15 ГБ |
| `/boot` | 2 ГБ, свободно 1.6 ГБ |
| `/boot/efi` | 1.1 ГБ, свободно 1.1 ГБ |

DEP-001 остаётся **не проверено**: на Ubuntu 24.04 стенд не запускался. Текущая ОС не соответствует требованию. Архитектура, CPU и общий объём RAM проходят пороги preflight скрипта, но это не подтверждает достаточность памяти и диска для полного стенда. Размер физического виртуального диска по `df` не установлен.

Пользователю предложены отдельная VM Ubuntu 24.04 либо обновление текущей VM. Он явно выбрал: «оставить так, как есть. будем так тестировать». ОС сохраняется Ubuntu 22.04.5; добавляется отдельный режим разработки для этой системы с подходящими Jammy-пакетами. Реальное развёртывание и изменение ОС не выполнялись. Результаты будущих проверок на 22.04 следует обозначать этой версией и не засчитывать как DEP-001.
