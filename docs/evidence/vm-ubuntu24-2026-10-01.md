# Развёртывание и сценарий на Ubuntu 24.04

Дата получения: 1 октября 2026, Europe/Moscow. Источник — [полный журнал, предоставленный пользователем](vm-ubuntu24-2026-10-01.log). Агент напрямую к VM не подключался; точная Git-ревизия не указана. Версия ОС и результаты ниже приводятся по этому журналу, без независимой проверки среды.

Команды: `cat /etc/os-release`, затем `make deploy && make verify && make verify-scenario`.

В журнале: `VERSION_ID="24.04"`, codename `noble`, OS-IMAGE `Ubuntu 24.04.5 LTS`; ARM64, Ready-узел `ubuntu`, Kubernetes v1.36.5, containerd 2.3.6, IP `192.168.64.5`. Образ собран с Docker cache и импортирован в containerd; Envoy Gateway v1.9.1 получил Helm revision 3. Существующие ресурсы, PVC и веса HTTPRoute сохранены.

Результаты:

- GatewayClass Accepted; Gateway Accepted/Programmed; demo и panel HTTPRoute Accepted/ResolvedRefs.
- HTTP 200 с ожидаемым JSON v1 через Gateway.
- Маркер `verify-905c309c2f5748038f3e959d058d0d9a` найден в конечном логе Fluentd в пределах 30 секунд; повторный verify подтвердил маркер `verify-823ab77f59ed4fc1ae654f38af5781dd`.
- Prometheus: свежие up samples всех пяти jobs и HTTP 200 counter v1.
- Панель и controller health: HTTP 200 / HTTP 200 по прямому IP VM.
- Здоровый canary: полное свежее окно, минимум 30 запросов v2; релиз завершён, HTTP v2 подтверждён.
- Ручной rollback: HTTP v1 подтверждён.
- Контролируемые ошибки v2: автоматический rollback по свежему 5xx решению, HTTP v1 подтверждён.
- Очистка сценария прошла: трафик остановлен, ошибки v2 выключены, ручной rollback и logout выполнены; итог `Scenario passed`.

DEP-001 подтверждён предоставленным журналом deploy и основных проверок на заявленной Ubuntu 24.04. Повторный deploy также подтверждён; чистое создание кластера на этой ОС в журнал не входит (DEP-002/004 остаются частично или не проверено). Не проверены восстановление pod, негативные Origin/CSRF сценарии в VM, ручная работа всех разделов панели, сохранность конкретных старых данных и расход ресурсов. Прежние журналы с другим OS-IMAGE сохраняются как история.
