# 02. Среда и воспроизводимость

### DEP-001 — Поддержка Ubuntu 24.04
Статус: обязательное. Источник: «Задание кратко»; «6. Поддержка операционной системы».

Требование: подтвердить работоспособность полного решения на Ubuntu 24.04.

Проверка: выполнить развёртывание и основные проверки на Ubuntu 24.04. Доказательство: версия ОС, команды, результаты проверок; заявление о совместимости без запуска недостаточно.

### DEP-002 — Независимость от инфраструктуры участника
Статус: обязательное. Источник: «Задание кратко»; «1. Kubernetes-окружение».

Требование: эксперты воспроизводят решение по Git-репозиторию без доступа к инфраструктуре участника.

Проверка: повторить путь с чистой среды по опубликованной инструкции. Доказательство: журнал запуска, необходимые входные данные и результаты.

### DEP-003 — Без обязательных коммерческих сервисов облака
Статус: обязательное. Источник: «1. Kubernetes-окружение».

Требование: обязательная часть не зависит от специфических коммерческих сервисов конкретного облачного провайдера.

Проверка: проверить зависимости и пройти воспроизведение без таких сервисов. Доказательство: список зависимостей и результат запуска.

### DEP-004 — Автоматизированное развёртывание
Статус: обязательное. Источник: «7. Автоматизация развертывания».

Требование: описанная последовательность действий разворачивает работоспособное решение без ручного создания и редактирования Kubernetes-ресурсов. Ручная настройка каждого ресурса в GUI недостаточна.

Проверка: выполнить инструкции с чистой среды, учитывая создание кластера и установку компонентов. Доказательство: команды, журнал и итоговые проверки.

### DEP-005 — Безопасный повторный запуск
Статус: обязательное. Источник: «7. Автоматизация развертывания».

Требование: повторный запуск процесса развёртывания не приводит систему в некорректное состояние.

Проверка: выполнить процедуру дважды и повторить проверки приложения, Gateway, метрик и логов. Доказательство: журналы обоих запусков и конечное состояние.

### DEP-006 — Учёт компонентов и зависимостей
Статус: обязательное. Источник: «1. Kubernetes-окружение»; «7. Автоматизация развертывания».

Требование: перечислить дополнительные компоненты, необходимые решению, и описать либо автоматизировать их установку; управлять версиями и зависимостями так, чтобы запуск по инструкции был воспроизводим.

Проверка: сравнить чистую установку с перечнем компонентов и инструкцией. Доказательство: версии, источники установки и результат.
