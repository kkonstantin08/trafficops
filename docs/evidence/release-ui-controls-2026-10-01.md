# Доступность действий canary

1 октября 2026. Пользователь сообщил перезапуск API по инструкции и прислал панель: состояние canary сохранилось; last_decision — insufficient or invalid v2 requests, смена веса отклонена. Полный вывод rollout/verify и сравнение старых записей журнала не предоставлены, поэтому сохранность журнала после рестарта отдельно не закрыта.

Причина отказа: активный canary допускает изменение веса и завершение только при полном свежем окне, минимум 30 запросах v2 и доле ошибок в пределах порога. Количество запросов всей серии или за 5 минут не подтверждает минимум v2 в текущем 60-секундном окне. Повторное начало активного релиза запрещено. Серверные ограничения сохранены.

Исправление `web/app.js` и `web/index.html`: кнопка начала недоступна при активном/завершённом релизе; смена доли и завершение доступны только при свежем безопасном last_decision без необходимости сверки. Пока операция выполняется, повторные действия отключены. Ручной rollback доступен авторизованному пользователю без зависимости от метрик. Начальное состояние закрыто до получения overview. Подсказка объясняет непрерывный трафик и текущие policy window/minimum; причины ожидания переведены на русский. Сохранены светлый стиль, текстовые объяснения и status region.

Проверки: `node tests/test_release_ui.js` сначала падал, после изменения проходит. Проверены active/stable/completed, unsafe/unknown/stale, reconcile_required, отсутствие авторизации, выполняющаяся операция и независимый rollback. `node --check web/app.js`, `git diff --check` — exit 0. Node проверка добавлена в CI. Полная визуальная проверка обновлённой панели и сценария её кнопок в VM остаётся открытой.
